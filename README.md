# oova-demo-react

Expo SDK 57 starter for an unofficial Oova concept demo. All data is sample data.

## Run

```sh
npm install
npx expo install --check
npm run typecheck
npm start
```

Press `i` for the iOS Simulator, or scan the QR code with Expo Go.

## Structure

- `src/app`: Expo Router screens
- `src/theme/tokens.ts`: design tokens
- `src/data/plan.ts`: scan plan builder
- `src/data/sample.ts`: fictional profile, chart, and unlock data

Project notes and the concept board are in `../docs`.
